# 模块路线

## 01 Deque

客服排队系统。重点是双端操作、对象集合、业务规则和边界。

## 02 PriorityQueue

任务调度系统。重点是优先级、稳定顺序、状态和有限重试。

## 03 async/await

耗时任务工作台。重点是Task、串行、并行、异常、取消和超时。

## 04 Channel

内存生产者消费者系统。重点是解耦、容量、背压和多消费者。

## 05 BackgroundService

后台任务Worker。重点是生命周期、优雅停止、异常和日志。

## 06 Task API

ASP.NET Core异步任务API。重点是DTO、分层、状态码和后台提交。
